# 소식·퍼나르기 안내

글을 한 번 쓰면 홈페이지 소식(`/story`)에 올라가고, 연결된 SNS에는 자동으로, 나머지는 복사해서 올리는 기능입니다.

## 어디서 쓰나요

관리자 > **소식·퍼나르기** (`/admin/stories.html`)

| 하는 일 | 방법 |
| --- | --- |
| 글 쓰기 | **새 글 쓰기** → 분류(스토리·뉴스·홍보), 제목, 본문, 이미지 입력 → **게시하기** |
| 예약 | 게시 시각을 뒤로 잡으면 그 시각에 홈페이지에 나타납니다. **시간 무작위**를 누르면 오전 9시~오후 9시 사이로 정해 줍니다. |
| 일주일 치 걸어 두기 | 글을 여러 편 **임시 저장**해 둔 뒤 **일주일 예약**을 누르면, 내일부터 하루 한 편씩 무작위 시각으로 예약합니다(최대 7편). |
| 퍼나르기 | 게시된 글의 **퍼나르기** → 자동 채널은 **지금 올리기**, 수동 채널은 **복사** 후 글쓰기 화면에 붙여 넣고 **올렸음** 표시 |

목록의 **퍼나를 글** 탭에는 아직 네이버 블로그·카페에 옮기지 않은 글만 모입니다. 수동 채널은 일주일에 한두 번 이 탭을 보고 옮기면 됩니다.

## 채널별 동작

| 채널 | 방식 | 비고 |
| --- | --- | --- |
| 홈페이지 소식 | 자동 | 게시 시각이 되면 바로 보입니다. |
| 페이스북 페이지 | 자동(연결 후) | 아래 "메타 연결"이 끝나야 합니다. |
| 인스타그램 | 자동(연결 후) | 이미지가 있는 글만 올라갑니다. |
| 네이버 블로그·카페 | 수동 | 네이버가 글쓰기 연동을 열어 두지 않아 복사해서 올립니다. |

자동 채널은 게시 시각이 지난 뒤 하루 일곱 번(오전 9시~오후 9시, 2시간 간격) 돌면서 올립니다. 실제 실행은 정해진 시각에서 한 시간 안쪽으로 늦을 수 있습니다. 같은 글을 두 번 올리지 않습니다.

## 검색에 나오게 하기

글마다 주소(`/story/글번호`)가 따로 생기고, 내용이 페이지에 들어 있어 네이버·구글이 한 편씩 가져갑니다.

- 사이트맵: `https://art.iux.kr/story/sitemap.xml` (robots.txt 에 등록됨, 글을 올리면 자동으로 늘어남)
- RSS: `https://art.iux.kr/story/rss.xml`

**처음 한 번 직접 해야 하는 일**

1. 네이버 서치어드바이저 > 요청 > **RSS 제출**에 `https://art.iux.kr/story/rss.xml` 추가
2. 같은 곳 > **사이트맵 제출**에 `https://art.iux.kr/story/sitemap.xml` 추가
3. 구글 서치콘솔 > Sitemaps 에 `story/sitemap.xml` 추가

검색에 실제로 나오기까지는 며칠에서 몇 주가 걸리고, 순위는 검색 엔진이 정합니다.

## 메타 연결 (페이스북·인스타그램 자동 올리기)

비밀번호를 넣는 방식이 아니라, 메타가 발급한 열쇠(토큰)를 Vercel 환경 변수에 넣는 방식입니다.

1. 인스타그램 계정을 **프로페셔널 계정**으로 바꾸고 페이스북 **페이지**에 연결합니다.
2. developers.facebook.com 에서 앱을 만들고, 그 앱으로 페이지 액세스 토큰을 발급합니다.
   필요한 권한: `pages_manage_posts`, `pages_read_engagement`, `instagram_basic`, `instagram_content_publish`
3. Vercel > 프로젝트 > Settings > Environment Variables 에 아래 값을 넣고 다시 배포합니다.

| 이름 | 값 |
| --- | --- |
| `META_PAGE_ID` | 페이스북 페이지 ID |
| `META_PAGE_TOKEN` | 페이지 액세스 토큰 (비밀 값) |
| `IG_USER_ID` | 페이지에 연결된 인스타그램 계정 ID |
| `CRON_SECRET` | 아무 긴 문자열. 예약 자동 올리기를 지키는 값입니다. |

- 토큰은 코드·채팅에 올리지 않습니다.
- 메타 권한 이름과 발급 화면은 자주 바뀝니다. 연결할 때 메타 개발자 문서를 다시 확인하세요.
- 값이 없으면 관리자 화면에 "연결 전"으로 나오고, 복사해서 올리는 방식으로만 동작합니다.

## 파일

```
lib/story.ts                     글 저장·불러오기, 공개 페이지 만들기 (틀: public/news-view.html)
lib/share.ts                     페이스북·인스타그램 올리기
app/story/                       공개 목록·글·사이트맵·RSS
app/api/admin/story/             관리자 저장·삭제·지금 올리기
app/api/cron/story/[slot]/       예약 실행 (vercel.json 의 crons)
public/admin/stories.html, js/stories.js   관리자 화면
```

- 글은 `iuxart.docs` 표에 `coll = 'stories'` 로 저장됩니다. 표를 새로 만들지 않습니다.
- 예전 `news.html`, `news-view.html` 주소는 `/story` 로 넘어갑니다. `news-view.html` 파일은 소식 페이지의 틀로 쓰므로 지우지 않습니다. 메뉴나 하단을 고치면 이 파일도 같이 고쳐야 소식 페이지에 반영됩니다.
